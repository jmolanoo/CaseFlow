**RUBRICA PROYECTO FINAL DE LA ASIGANTURA INGENIERÍA DE SOFTWARE – ELECTIVA 1 SOLICITUD:** 

Al finalizar el semestre, como evaluación correspondiente al parcial final, deberán  desarrollar una aplicación Cliente Servidor que resuelva una necesidad específica de un  modelo de negocio o una situación particular. El trabajo se realizará en grupos de máximo  tres integrantes. 

**Objetivo:** Desarrollar un proyecto de desarrollo de software, haciendo uso de  herramientas de Inteligencia artificial. 

Términos: 

1\. En el proyecto debe haber un rol de cliente externo para la validación del sistema. 2\. El desarrollo debe hacer uso de herramientas de IA 

3\. El uso de herramientas es de libre selección por el equipo de trabajo. 4\. La aplicación deberá implementar una arquitectura distinta a la monolítica.  Asimismo, explicar el proceso de desarrollo adoptado, evidenciando la aplicación de  buenas prácticas con IA. 

5\. Establecer el alcance del proyecto, teniendo presente el tiempo. 

6\. Cumplir con la documentación exigida. 

7\. Sustentación del proyecto final: Exponer el proyecto en el evento INNOVASOFT IX versión, para el día 19 de noviembre. 

8\. La aplicación puede ser delegada de forma local o Cloud (tendrá un mayor valor en  la calificación) 

9\. El proyecto se desarrolla con Inteligencia Artificial, es obligatorio incluir un apartado  detallado (Integración IA) que explique la arquitectura de la solución implementada.  Esta sección debe especificar: la herramienta o modelo de IA utilizado, las  instrucciones (prompts) empleadas, así como los mecanismos de control, reglas de  negocio, agentes, skills y cualquier otro componente técnico integrado en el  desarrollo del software y según las consideraciones expuestas de acuerdo a:
